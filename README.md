# Frontend
## Inspiration
Online scams, phishing websites, and fake news are spreading faster than ever. In 2024, nearly 3 million phishing incidents in Malaysia caused over RM1.5 billion in losses. Many users think they can spot fake sites, but scammers are getting increasingly sophisticated. We wanted to create a tool that helps users instantly verify the trustworthiness of any website or link before they click.

## What it does
RealCheck AI evaluates any website or link in real-time and produces a risk score with a clear explanation. It analyzes domain information, SSL certificates, URL structure, textual patterns, and cross-checks known scam databases. Users can see at a glance whether a website is safe or suspicious, helping them avoid scams and misinformation.

## Components
Front end, Google browser extension, backend
